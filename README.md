# 🖥️ Montador de PC

O **Montador de PC** é uma aplicação web simples e interativa desenvolvida para ajudar usuários a simularem e calcularem o custo total na escolha dos componentes de um computador.

> 🚀 **Acesse o projeto online:** [Clique aqui para testar](https://joaopedrordev.github.io/Montagem-de-PC/)

---

## ✨ Funcionalidades

- Seleção de componentes essenciais (Processador, Placa de Vídeo, Memória RAM e Armazenamento).
- Cálculo dinâmico do valor total da montagem.
- Destaque nos campos de seleção pendentes ao calcular.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação do conteúdo e elementos do formulário.
- **CSS3** — Estilização personalizada com tema escuro.
- **JavaScript** — Lógica de cálculo do preço total e manipulação do DOM.
