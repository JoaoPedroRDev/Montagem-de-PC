# 💻 Montador de PC Web

Um site interativo desenvolvido para auxiliar usuários a simular o orçamento e a montagem de um computador. O usuário seleciona os componentes desejados e o sistema calcula automaticamente o valor total da configuração[cite: 1, 2].

---

## 🚀 Funcionalidades

- **Seleção de Componentes:** Processadores, Placas de Vídeo, Memória RAM e Armazenamento[cite: 1].
- **Cálculo Automático:** Soma os valores dos itens selecionados dinamicamente[cite: 1, 2].
- **Validação Visual:** Destaque em bordas coloridas nos seletores para indicar preenchimento[cite: 2].

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do projeto[cite: 1].
- **CSS3:** Estilização com tema escuro e detalhes em dourado[cite: 3].
- **JavaScript (ES6):** Manipulação de DOM, regras de negócio e cálculo dos totais[cite: 2].
